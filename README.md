# 100 Days of Code - C Programming

Solutions for the UPES C programming coding challenge.

## Repository Structure

- `Day-01` to `Day-50`: two C programs per day.
- `Day-51` onward: one logic-enhancer program per day.
- Each source file includes the day and question number at the top.

## Running a Program

```bash
gcc program.c -o program
./program
```

Programs using `math.h` may require `-lm` on some systems.
